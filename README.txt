শব্দকল্প – অফলাইন অ্যাপ

১. এই ফোল্ডারের সব ফাইল (index.html, sw.js, manifest.webmanifest, icons/) HTTPS হোস্টিংয়ে আপলোড করুন
   (GitHub Pages / Netlify / Cloudflare Pages)।
২. ফোনে লিংকটি ইন্টারনেট সহ একবার খুলুন। "অ্যাপ এখন ইন্টারনেট ছাড়াই চলবে ✓" বার্তা এলে সবকিছু (ফন্ট ও PDF লাইব্রেরি সহ) ফোনে সংরক্ষিত হয়ে গেছে।
৩. Android Chrome: ⋮ → Install app। iPhone Safari: Share → Add to Home Screen।
৪. এরপর ইন্টারনেট ছাড়াই লেখা, সংরক্ষণ ও PDF তৈরি করা যাবে।

লেখা ফোনের লোকাল স্টোরেজে থাকে। ব্রাউজারের ডেটা মুছলে লেখাও মুছে যাবে।
আপডেট দিলে sw.js-এর VERSION নাম বদলে দিন।

এক্সপোর্ট (v11): নিচের “এক্সপোর্ট” বা উপরের PDF বাটনে চাপুন → PDF অথবা Word (.docx) বেছে নিন → ফাইল প্রস্তুত হলে “ডাউনলোড” চাপুন।
ডাউনলোড না হলে “বিকল্প ডাউনলোড” বা (থাকলে) “শেয়ার / অন্য অ্যাপে সংরক্ষণ” ব্যবহার করুন।
